### La sycophancie : quand l'IA nous dit ce que nous voulons entendre

La **sycophancie** (en français : *complaisance* ou *flagornerie de l'IA*, termes recommandés par
l'OQLF) désigne la tendance d'un modèle de langage à s'aligner sur l'opinion, le ton ou les
prémisses de son interlocuteur plutôt que sur les faits.

Ce n'est pas un bug isolé mais une conséquence assez directe du mode d'entraînement : les modèles
sont optimisés sur des préférences humaines, et les humains préfèrent — en moyenne — les réponses
qui leur donnent raison. Le mécanisme est documenté : des données de préférence qui favorisent
l'accord produisent un modèle de récompense qui favorise l'accord, donc un modèle final complaisant.
