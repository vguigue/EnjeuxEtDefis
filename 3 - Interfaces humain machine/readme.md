# IA et interface avec les humains

Plusieurs aspects de la question peuvent être étudiés: 
- l'IA comme moyen de communication, le brain computer interface, le déchiffrage des langues des signes...
- l'IA comme compagnon en milieu *controlé* (hopitaux, par exemple pour le traitement de l'autisme; maison de retraite, pour multiplier les interactions...)
- l'IA en milieu ouvert: les risques psychologiques liés à la multiplication des chatbots et les nouveaux usages.
